# NetShop Partner Management System

ネットショップ共同運営のための、多階層（ピラミッド型）代理店・案件管理プラットフォームです。

## 🚀 主な機能

- **ダッシュボード**: 案件のステータス（審査中、要修正、承認済み）をリアルタイムで可視化。
- **案件管理**: 楽天、Yahoo!ショッピング、Amazon等のプラットフォーム別案件登録・進捗管理。
- **代理店ネットワーク**: 親代理店・子代理店の紹介関係（ツリー構造）の管理と可視化。
- **審査ワークフロー**: 管理者による書類確認、差戻し（理由テンプレート付き）、承認フロー。
- **招待システム**: 管理者または代理店専用の有効期限付き招待URL発行機能。
- **監査ログ**: 全ユーザーの重要な操作履歴をすべて記録。
- **ダークモード対応**: モダンなUI/UX。

## 🛠 技術スタック

- **Frontend**: React 19 (TypeScript)
- **Styling**: Tailwind CSS
- **Routing**: React Router 7
- **Build Tool**: Vite
- **Deployment**: Vercel

## 📦 セットアップ

1. 依存関係のインストール:
   ```bash
   npm install
   ```

2. 開発サーバーの起動:
   ```bash
   npm run dev
   ```

3. ビルド:
   ```bash
   npm run build
   ```

## 🌐 デプロイ方法 (Vercel)

1. このリポジトリをGitHubにプッシュします。
2. [Vercel](https://vercel.com/) にログインし、「Add New Project」からこのリポジトリを選択します。
3. Framework Preset に `Vite` を選択し、「Deploy」をクリックします。
